# Podcastly 🎙

A studio-quality podcast recording platform built with WebRTC, Node.js, and React.

## Live Demo
- Frontend: https://podcastly-mu.vercel.app
- Backend: https://podcastly-backend.onrender.com

## Tech Stack

**Frontend**
- React.js + TypeScript
- Vite
- Custom CSS (no UI library)

**Backend**
- Node.js + Express.js
- Prisma + PostgreSQL (Neon)
- BullMQ + Redis (Upstash)
- Supabase Storage

**Real-time**
- WebRTC (peer-to-peer video/audio)
- WebSocket signaling server

## Features
- 🎙 Local-first recording via MediaRecorder API
- ⚡ WebRTC peer-to-peer connections
- ☁️ Automatic cloud upload
- 🔀 Separate tracks per participant
- 🔑 Session codes for guest invites
- 📊 Producer dashboard
